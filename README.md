# 디지털논리회로 마스터

디지털 논리 회로 Ⅰ~Ⅶ단원 배우기 · 게이트 게임 4종 · 종합시험.

- 주소 : https://hongyul67-cpu.github.io/digital-logic-master/
- 대상 : 전기제어과 1학년 「디지털 논리 회로」
- 만든 날 : 2026-09-04

## 화면

| 화면 | 내용 |
|---|---|
| 📖 배우기 | 단원 Ⅰ~Ⅶ · 개념 38개. **정답을 다 보여 주는 단계** — 앞에 둡니다 |
| 🎮 게임 | 진리표 채우기 · 회로 조립 · 카노맵 묶기 · 2진 변환 속도전 |
| ✏️ 연습 | 8문항 · 고르면 바로 정답과 해설 |
| 🏁 종합시험 | 20문항 · 끝날 때까지 아무것도 알려주지 않음(규약 2) |
| 📕 오답노트 | 틀린 문항이 쌓임 |

게임 문제는 **그때그때 새로 만들어 냅니다**(저작물이 아니고, 같은 문제가 반복되지 않습니다).
카노맵은 양쪽 끝이 이어지는 묶음까지 인정하고, "더 크게 묶을 수 있다"를 잡아냅니다.
회로 조립은 팔레트에서 XOR·XNOR 를 빼서 기본 게이트만으로 만들게 합니다.

## 잠금 — 왜 코드가 필요한가

배우기 내용이 교과서를 정리한 자료여서 **파일 자체를 AES-GCM 으로 암호화**해 올립니다
(`bank.enc`). 화면에 비밀번호 칸만 두면 정적 호스팅에서는 보호가 되지 않습니다.

| | 형태 | 유효기간 |
|---|---|---|
| 교사용 | 문구형 (도구 공용) | 없음. 열면 그 주 학생 코드가 화면에 나옵니다 |
| 학생용 | 8자리 숫자 (도구 공용) | 그 주 월요일 ~ 다음 월요일 |

한 기기에서 한 번 열면 같은 주소의 다른 도구도 그냥 열립니다(`hong_pw_v1`).
